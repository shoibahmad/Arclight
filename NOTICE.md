# Third-party notices

Arclight bundles one third-party component.

## Three.js

- Version: r186
- Location in this repository: `vendor/three/`
- Files: `three.module.js`, `three.core.js`
- Licence: MIT — full text in `vendor/three/LICENSE`
- Home: https://threejs.org

Three.js is vendored rather than installed from npm so that the project runs
from a clean clone with no install step and no network access. The files are
the unmodified published build.

## Everything else

All other content in this repository — source code, circuit layouts, craft
designs, textures, geometry, audio and interface — is original work by the
copyright holder named in `LICENSE`.

There are no bundled texture, model, font or audio files. Every asset is
generated at runtime by code in this repository:

| Asset type | Generated by |
| --- | --- |
| Surface textures, normal and ORM maps | `src/assets/Textures.js`, `src/assets/Noise.js` |
| Track, craft, scenery geometry | `src/assets/MeshBuilder.js` and the builders in `src/track/`, `src/game/` |
| Sky, environment map | `src/render/Sky.js`, `src/render/Environment.js` |
| Engine sound, effects, music | `src/audio/AudioEngine.js` |
| Typography | system font stacks only (see `styles/main.css`) |
